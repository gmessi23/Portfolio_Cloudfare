Two tools, two jobs.

Microsoft Foundry

The model layer

I deploy the models there and point the app at them. Each agent in my apps has its own deployment, so I can tune cost and quality one step at a time and swap a model without touching the code.

Claude Code

The build layer

I describe the change, read the diff it proposes, and run the result. It works across the whole repository, so a job like porting a Python API to a TypeScript Worker stays one reviewable change.

From idea to live app

  1. 1 Frame the job

    One user, one question the app answers, and the data it needs to answer it.

  2. 2 Build in small steps

    Claude Code makes each change. I read the diff and run it before the next one.

  3. 3 Check real output

    I ask real questions, read the failures, then tighten prompts and limits, such as a cap of three searches.

  4. 4 Ship behind a login

    The app runs on Cloudflare. Cloudflare Access decides who can use the paid models.

Research Desk

Ask a question and get an executive report. Three agents search the live web, analyse what they find, and write a structured report in English or French.

The report can be copied, downloaded as Markdown, or printed. Follow-up questions run the whole pipeline again with one click.
